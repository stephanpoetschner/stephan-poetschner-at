# Mock-ups

Design directions from 2026-11-05, kept as reference for DESIGN.md. Static HTML, open via
`python3 -m http.server` in this folder.

- `a.html` Raster: Swiss grid, Hanken Grotesk, vermilion signal
- `b.html` Feld: colour fields, Schibsted Grotesk, deep green / sand
- `c.html` Stille: one typeface, size and weight contrast, Instrument Sans
- `d.html` C with B colours: the chosen direction

Copy in the mock-ups is a draft; the live text is in `portfolio/templates/index.html`.
Fonts are OFL (fontsource).
